# Bug Record: BUG-2026-07-16-001

## Summary

- Title: Testimonial rail reaches empty space during manual horizontal scroll
- Current status: `fix-attempted`
- Severity: `medium`
- Owner: Diane
- Next command: `/005-sg-ship -> /405-sg-prod -> /107-sg-test --preview --retest BUG-2026-07-16-001`

## Reproduction

- Preconditions:
  - Open the public English or French landing page with the testimonial rail rendered below the hero.
  - Use a pointer, trackpad, touch gesture, or keyboard-capable horizontal scroll surface.
- Steps:
  1. Hover or focus the rail so its automatic CSS animation pauses.
  2. Scroll horizontally toward the right through both rendered testimonial copies.
  3. Continue until the native scroll container reaches its physical end.

## Expected Behavior

- The testimonial sequence loops continuously in either horizontal direction.
- Manual interaction never exposes an empty trailing area.
- Automatic motion pauses during interaction and resumes afterward.
- Reduced-motion users receive a finite, manually scrollable list without forced animation.

## Observed Behavior

- The native scroll container can reach the end of its two physical copies while the track is also translated by CSS animation.
- At that point, the viewport can show empty space instead of cycling to the first testimonial.

## Evidence

- User reproduction report in the active landing-page conversation.
- `site/src/components/Testimonials.astro`: two copies are rendered but no manual scroll normalization exists.
- `site/src/styles/global.css`: `.testimonial-rail` is a native overflow scroller while `.testimonial-rail__track` is independently translated by the `marquee` keyframes.
- No secrets, private payloads, account data, cookies, tokens, or personal runtime logs were collected.
