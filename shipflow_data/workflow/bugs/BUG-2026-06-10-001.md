# Bug Record: BUG-2026-06-10-001

## Summary

- Title: Android bootstrap fallback reports Clerk as missing
- Current status: `fix-attempted`
- Severity: `high`
- Owner: Diane
- Next command: `/sf-test --retest BUG-2026-06-10-001`

## Reproduction

- Preconditions:
  - Install the Android debug APK produced by GitHub Actions run `27300444261`.
  - Open the app on a real Android device.
- Steps:
  1. Launch ReplayGlowz.
  2. Wait for bootstrap to complete.
  3. Read the fallback diagnostics screen.

## Expected Behavior

- Android uses Firebase native auth configuration, not Clerk web configuration.
- The fallback screen should not report `CLERK_PUBLISHABLE_KEY` as a required Android secret.
- Diagnostics should be copyable from a visible control on small mobile screens.

## Observed Behavior

- The app enters the bootstrap fallback screen.
- Diagnostics report `CLERK_PUBLISHABLE_KEY` as missing even though Clerk is not the Android auth owner.
- The user cannot see an obvious copy logs button on the installed app.

## Evidence

- User report on 2026-06-10: "the app started but bootstrap failed" and "clerk publishable key missing".
- User report on 2026-06-10: no visible button for copying logs.
