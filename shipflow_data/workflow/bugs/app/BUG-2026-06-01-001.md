# Bug Record: BUG-2026-06-01-001

## Summary

- Title: Feed filter picker is too short on mobile
- Current status: `fixed-pending-verify`
- Severity: `medium`
- Owner: Diane
- Next command: `/sf-test --retest BUG-2026-06-01-001`

## Reproduction

- Preconditions:
  - A signed-in user has enough ReplayGlowz feeds for the feed filter list to scroll.
  - The Feed page is opened in a mobile-sized viewport.
- Steps:
  1. Open the Feed page.
  2. Tap the filter picker.
  3. Try to view many feed options without excessive internal scrolling.

## Expected Behavior

- The feed filter drawer can be pulled substantially higher, close to the top of the screen, so users can see more feed options at once.
- The internal feed list remains scrollable.

## Observed Behavior

- The drawer is limited to a short bottom-sheet layout and the feed list is constrained inside it, so only a small number of feeds are visible at once.

## Evidence

- `app/lib/screens/videos/videos_screen.dart` used `showModalBottomSheet` without `isScrollControlled` and constrained the list height to `MediaQuery.height * 0.6`.
- Operator report on 2026-06-01.
