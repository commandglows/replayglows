# Bug Record: BUG-2026-09-05-001

## Summary and bounded contract

The operator approved reconnecting the existing bookmark functionality and testing add, revisit, edit, delete, shortcuts, persistence and import/export in a dedicated Canary profile. Extension only; no backend, dependency migration, global browser changes or unrelated worktrees.

Classification: direct repairs inside the explicitly approved plan; evidence-first for disconnected entry points, regression-first for persistence boundaries. Expected legacy storage remains a flat `bookmarks` array with `url`, `time`, `formattedTime`, `note` and optional `title`, plus derived `groupedBookmarks`. Old options `videoId`/`timestamp` imports are also accepted. Import replacement is explicit and requires an in-product confirmation; invalid imports leave storage unchanged.

## Reproduction

Build ext, load dist unpacked, open a public YouTube watch page and press Alt+B or open the popup. Before repair: no bookmark input, logging-only content/background entry points, popup main.ts mounting placeholder App.vue. Existing legacy code was never bundled.

## Expected Behavior

A timestamped note is saved once, listed, editable, deletable, revisitable and retained across pages/worker/browser restarts. Existing data stays compatible. User text is rendered as text. Keyboard shortcuts do not act while editing text. Other videos and concurrent tabs must retain their records.
