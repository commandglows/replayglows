# Bug Record: BUG-2026-05-30-001

## Summary

- Title: Adding an already-added Feed source can show a server error
- Current status: `fix-attempted`
- Severity: `medium`
- Owner: Diane
- Next command: `/sf-test --retest BUG-2026-05-30-001 after next ship`

## Reproduction

- Preconditions:
  - Authenticated user has at least one ReplayGlowz Feed.
  - At least one YouTube playlist is available as a source candidate.
- Steps:
  1. Open a Feed detail screen.
  2. Click `Add source`.
  3. Choose a playlist source.
  4. Observe whether a server error appears even though the source is later visible in the Feed.

## Expected Behavior

- Adding a source should either add it successfully or, if the source is already present because of a stale UI/double action/race, treat the operation as successful.
- The user should not see a generic server error when the final Feed state is correct.

## Observed Behavior

- The user saw: `Could not add source: Error: [Request ID: db7562ab9f55de7a] Server Error`.
- The Feed still appeared to work afterward and `Play all` launched videos from the connected source.
