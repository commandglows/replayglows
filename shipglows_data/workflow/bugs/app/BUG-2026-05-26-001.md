## Reproduction

- Preconditions:
  - Production app at `https://app.replayglowz.com`.
  - Authenticated ReplayGlowz test account.
  - Convex auth ready.
- Steps:
  1. Open `https://app.replayglowz.com/preferences` directly.
  2. Wait for bootstrap and Convex auth.
  3. Observe the rendered page.
  4. Repeat with `https://app.replayglowz.com/playlists`.

## Expected Behavior

- `/preferences` renders Preferences.
- `/playlists` renders Playlists.
- Sidebar navigation updates browser route or hash so reload/deep links preserve the visible page.

## Observed Behavior

- Direct `/preferences` rendered the Videos page.
- Direct `/playlists` rendered the Videos page.
- Sidebar navigation can reach Preferences/Playlists visually, but the browser URL remains `/videos`.
