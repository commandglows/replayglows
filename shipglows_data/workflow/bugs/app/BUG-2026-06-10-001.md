# Bug Record: BUG-2026-06-10-001

## Summary

- Title: Android bootstrap fails before Firebase and Convex initialise
- Current status: `fixed-pending-verify`
- Severity: `high`
- Owner: Diane
- Next command: install GitHub Actions run `27305689222` artifact `replayglowz-app-debug-apk` and retest on device

## Reproduction

- Preconditions:
  - Install the Android debug APK produced by GitHub Actions run `27302777396`.
  - Open the app on a real Android device.
- Steps:
  1. Launch ReplayGlowz.
  2. Wait for bootstrap to complete.
  3. Read the fallback diagnostics screen.

## Expected Behavior

- Android initialises Firebase before any native auth adapter reads `FirebaseAuth.instance`.
- Android initialises Convex without a `flutter_rust_bridge` runtime/codegen mismatch.
- Android uses Firebase native auth configuration, not Clerk web configuration.
- The fallback screen should not report `CLERK_PUBLISHABLE_KEY` as a required Android secret.
- Diagnostics should be copyable from a visible control on small mobile screens.

## Observed Behavior

- Run `27300444261`: the app entered the bootstrap fallback screen, reported `CLERK_PUBLISHABLE_KEY` as missing even though Clerk is not the Android auth owner, and did not expose an obvious copy logs button on the installed app.
- Run `27302777396`: diagnostics correctly showed `CLERK_PUBLISHABLE_KEY: not required on native`, but app bootstrap still failed because `NativeFirebaseAuthSessionAdapter` touched `FirebaseAuth.instance` before `FirebaseBootstrap.initialise()`.
- Run `27302777396`: recent logs also showed Convex native initialisation failed because `convex_flutter` generated bindings expected `flutter_rust_bridge` `2.11.1` while pub resolved runtime `2.12.0`.

## Evidence

- User report on 2026-06-10: "the app started but bootstrap failed" and "clerk publishable key missing".
- User report on 2026-06-10: no visible button for copying logs.
- User-provided diagnostics on 2026-06-10 from commit `171f209d4121a7a587a0d50994244b933149d54a`: `[core/no-app] No Firebase App '[DEFAULT]' has been created - call Firebase.initializeApp()`.
- User-provided diagnostics on 2026-06-10 from commit `171f209d4121a7a587a0d50994244b933149d54a`: `convex_flutter's codegen version (2.11.1) should be the same as runtime version (2.12.0)`.
