# Bug Record: BUG-2026-05-24-003

## Summary

- Title: WinFlowz account center button does not react
- Current status: `closed`
- Severity: `medium`
- Owner: Diane
- Next command: `closed`

## Reproduction

- Preconditions:
  - User is on the ReplayGlowz sign-in or product-access screen.
- Steps:
  1. Click `Open WinFlowz account center`.
  2. Observe whether the browser navigates to the account center.

## Expected Behavior

- The button should open the configured WinFlowz account center URL directly.

## Observed Behavior

- The button can appear to do nothing because it calls Clerk user-profile UI first, which is not a reliable account-center navigation path for unauthenticated users.

## Evidence

- `AuthService.openUserProfile()` delegates to the Clerk bridge.
- `web/clerk_bridge.js` calls `clerk.openUserProfile()` before using `state.accountCenterUrl`.
- `flutter analyze` completed with no issues.
- `rg` verified account-center button handlers now call `openAccountCenter()`.
