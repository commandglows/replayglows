# Bug Record: BUG-2026-05-25-001

## Summary

- Title: YouTube refresh fails for newly connected empty accounts
- Current status: `fixed-pending-verify`
- Severity: `high`
- Owner: Diane
- Next command: `/sf-fix BUG-2026-05-25-001`

## Reproduction

- Preconditions:
  - Production ReplayGlowz app.
  - Signed-in ReplayGlowz user.
  - YouTube connected with a fresh Google account that may have no YouTube subscriptions, playlists, or channel history.
- Steps:
  1. Open ReplayGlowz preferences.
  2. Connect YouTube.
  3. Trigger refresh/sync.

## Expected Behavior

- The sync should complete with a friendly empty-library state when YouTube returns no playlists, subscriptions, or videos.
- The app should not show a raw Convex server error for a valid empty YouTube account.

## Observed Behavior

- The app shows `Refresh failed: Error: [Request ID: ...] Server Error`.
- Client diagnostics show `youtube:startQuotaSafeSync` failed through the Convex HTTP bridge.

## Evidence

- Production client logs from 2026-05-25 show `Convex HTTP action bridge failed for youtube:startQuotaSafeSync`.
- Request ID and user ID were shared in chat context; raw identifiers are omitted here.
