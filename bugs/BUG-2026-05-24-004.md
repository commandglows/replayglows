# Bug Record: BUG-2026-05-24-004

## Summary

- Title: Google sign-in through Clerk reports redirect_uri_mismatch
- Current status: `needs-info`
- Severity: `high`
- Owner: Diane
- Next command: Update Google Cloud OAuth client authorized redirect URI from Clerk Dashboard

## Reproduction

- Preconditions:
  - User visits the hosted ReplayGlowz app sign-in page.
  - User starts Google sign-in from the Clerk widget.
- Steps:
  1. Open `https://app.replayglowz.com/sign-in?tf_redirect=/videos`.
  2. Click Google in the Clerk sign-in widget.
  3. Observe Google's OAuth error page.

## Expected Behavior

- Google accepts the redirect URI generated by Clerk and returns the user to Clerk, then ReplayGlowz.

## Observed Behavior

- Google returns `redirect_uri_mismatch`.

## Evidence

- Production app uses a public Clerk live key with frontend API domain `clerk.replayglowz.com`; the key itself was not recorded.
- `curl -sSI https://app.replayglowz.com/sign-in?tf_redirect=/videos` confirms the hosted app is served by Vercel and allows `clerk.replayglowz.com` in CSP.
- Official Clerk docs say production Google social connections require custom credentials and that the Authorized Redirect URI from Clerk Dashboard must be pasted into Google Cloud's Authorized Redirect URIs.
