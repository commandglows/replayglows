# Bug Record: BUG-2026-05-24-001

## Summary

- Title: Marketing CTAs bypass sign-in redirect
- Current status: `closed`
- Severity: `medium`
- Owner: Diane
- Next command: `closed`

## Reproduction

- Preconditions:
  - User is on the public ReplayGlowz marketing site.
  - User is not already authenticated in the ReplayGlowz app.
- Steps:
  1. Open the ReplayGlowz landing page.
  2. Click a primary marketing CTA such as `Start Organizing for Free`.
  3. Observe the destination URL.

## Expected Behavior

- Marketing conversion CTAs should send anonymous users to `https://app.replayglowz.com/sign-in?tf_redirect=/videos` so sign-in can complete and then land on `/videos`.

## Observed Behavior

- CTAs linked directly to `https://app.replayglowz.com/videos`, which can leave the app on a blank protected route for anonymous users.

## Evidence

- `rg -n "appUrl\\(" replayglowz_site/src` found multiple CTA links targeting `appUrl('/videos')`.
- `replayglowz_app/lib/app/router.dart` uses `tf_redirect` on `/sign-in` for protected-route redirects.
- `npm run build` completed successfully in `replayglowz_site`.
- Generated HTML checks found zero direct `https://app.replayglowz.com/videos` links and 64 `https://app.replayglowz.com/sign-in?tf_redirect=/videos` links.
- Source and generated HTML checks found no remaining `href="#"` placeholder links.
