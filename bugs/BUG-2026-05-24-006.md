# Bug Record: BUG-2026-05-24-006

## Summary

- Title: Production Convex auth requests obsolete Clerk JWT template
- Current status: `fix-attempted`
- Severity: `high`
- Owner: Diane
- Next command: `/sf-prod app.replayglowz.com after app changes are deployed`

## Reproduction

- Preconditions:
  - Production app at `https://app.replayglowz.com`.
  - Clerk production publishable key is configured.
  - User has or restores a Clerk session.
- Steps:
  1. Open `https://app.replayglowz.com/`.
  2. Let the Flutter bootstrap initialise Clerk and wire Convex auth.
  3. Observe the bootstrap diagnostics fallback.

## Expected Behavior

- The app should load without a blocking bootstrap diagnostics screen.
- If Convex auth token minting is unavailable, the app should continue into guarded/local fallback states and log a warning.
- Production Clerk should provide a session token carrying the Convex audience from the Clerk Convex integration.

## Observed Behavior

- Production displays `ReplayGlowz bootstrap diagnostics`.
- Bootstrap logs report `No JWT template exists with name: convex` with status `404` while the app is requesting an obsolete custom template.
- Logs show the failure occurs after Clerk initialisation and Convex auth wiring.
- YouTube connect reports access inactive because `productAccessStatusProvider` cannot verify access without Convex auth and fails closed.

## Evidence

- Redacted operator diagnostics:
  - Build commit: `2cde1982b44860ae796fd8483da08e44fbec1a3e`
  - Environment: `production`
  - Host: `app.replayglowz.com`
  - Convex URL: configured
  - Clerk publishable key: configured and redacted
  - Error: `No JWT template exists with name: convex`
- Original local code path:
  - `replayglowz_app/lib/auth/auth_service.dart` called Clerk token minting with template `convex`.
  - `replayglowz_backend/packages/backend/convex/auth.config.ts` expects Convex audience `convex`.
